Documentation technique

TV Tracker est une application de suivi de séries et de films : statuts de visionnage, épisodes vus, notes, calendrier, statistiques et amis. Cette documentation décrit comment le projet est construit, comment le lancer avec Docker et comment il fonctionne en interne.

Accès local. Cette documentation est servie par Nginx à l'adresse http://localhost:8080/documentation. Elle n'est pas protégée par mot de passe, car l'environnement est local.

Structure du dépôt

tv-tracker/
├── docker-compose.yml        Orchestration des 3 services
├── README.md                 Guide d'installation (historique, sans Docker)
├── documentation/            Cette documentation (servie sur /documentation)
├── backend/
│   ├── Dockerfile
│   ├── .env                  Secrets locaux (jamais copiés dans l'image)
│   ├── .env.example          Modèle de .env sans valeurs
│   ├── scripts/              Scripts ponctuels (import TV Time)
│   └── src/
│       ├── app.js            Point d'entrée Express
│       ├── routes/           Une route par domaine fonctionnel
│       ├── services/         Logique métier et appels TMDB
│       ├── middleware/       Authentification (requireAuth)
│       ├── cron/             Tâche planifiée quotidienne
│       └── db/               Connexion, migrate.js, migrations SQL
└── frontend/
    ├── Dockerfile            Build Vite puis image Nginx
    ├── nginx.conf           Proxy /api et service de /documentation
    └── src/
        ├── pages/            Une page par écran
        ├── components/       Composants réutilisables
        ├── context/          AuthContext (session utilisateur)
        ├── api/client.js     Instance axios (baseURL /api)
        └── constants/        Statuts et leurs libellés
