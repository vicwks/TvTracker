Référence API

Toutes les routes sont préfixées par /api. Depuis le navigateur, elles passent par Nginx sur http://localhost:8080.

Authentification

La session est un JWT signé avec JWT_SECRET, valable 30 jours, stocké dans un cookie HTTP-only nommé token (SameSite=Lax). Les routes marquées auth exigent ce cookie ; sans lui, ou avec un jeton invalide, la réponse est 401.

Santé

MéthodeRouteAccèsDescription
GET/api/healthpublicRenvoie { "ok": true, "db": true } si la base répond, 503 sinon. Utilisé par le healthcheck Docker.

Format des erreurs

Toutes les erreurs sont renvoyées en JSON, sous la forme { "error": "message" }, sans détail technique interne.

CodeCas
400Donnée invalide (statut inconnu, note hors de 0 à 10, JSON malformé...)
401Non connecté, ou identifiants incorrects
404Ressource introuvable, ou identifiant TMDB inconnu
409Conflit (pseudo déjà pris, demande d'ami déjà envoyée)
429Trop de tentatives de connexion ou d'inscription (20 par IP toutes les 15 minutes)

Authentification et compte

MéthodeRouteAccèsDescription
POST/api/auth/registerpublicCrée un compte à partir de { email, username, password }. Le nom affiché prend la valeur du pseudo. Le tout premier compte récupère les données déjà présentes en base.
POST/api/auth/loginpublicVérifie le mot de passe et pose le cookie token.
POST/api/auth/logoutpublicSupprime le cookie.
GET/api/auth/meauthProfil de l'utilisateur connecté.
PATCH/api/auth/meauthModifie le profil (nom affiché, avatar).
PATCH/api/auth/usernameauthChange le pseudo { username }. Le pseudo sert aussi de nom affiché. Limité à 20 tentatives par IP toutes les 15 minutes.
PATCH/api/auth/passwordauthChange le mot de passe { current_password, new_password }. Le mot de passe actuel est vérifié. Même limite que ci-dessus.
POST/api/auth/avatarauthEnregistre la photo { image } (data URL JPEG déjà réduite par le navigateur, 300 Ko maximum). Stockée dans la table user_avatars.
DELETE/api/auth/avatarauthRetire la photo : l'icône reprend l'initiale du nom.
GET/api/auth/avatar/:idauthImage de profil d'un utilisateur (visible des amis).
